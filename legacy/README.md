# legacy

The original project sketch: a round GC9A01A TFT display showing
temperature/humidity gauges driven by a DHT11 sensor. No soil sensing.
Archived here as a reference, not part of the active build — it may become
the eventual on-device UI stage once the impedance-probe sensing pipeline
(see the repo root) is validated. See
[`../docs/changelog.md`](../docs/changelog.md) for when and why this moved.
